
# SmartBudget Manager

SmartBudget Manager is an Excel workbook designed to help users manage their monthly budget.

## Features
- Record monthly income and expenses.
- Categorize expenses.
- Calculate the monthly balance automatically.
- Display charts of expenses by category.
- Show a warning when the budget limit is exceeded.

## Workbook Worksheets
- **Dashboard:** Shows monthly balance, total income, total expenses, and charts.
- **Transactions:** Allows users to enter income and expenses.
- **Categories:** Contains predefined categories such as Food, Transport, Rent, Health, and Education.

## Requirements
Microsoft Excel 2016, 2019, 2021, Microsoft 365, or an equivalent compatible version.

## Getting Started
1. Open the SmartBudget_Manager.xlsx workbook.
2. Go to the Transactions worksheet.
3. Enter your income and expenses.
4. Select the appropriate expense categories.
5. Check the Dashboard to view your monthly financial summary.
